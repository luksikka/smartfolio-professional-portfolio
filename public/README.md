# How to Add Your Profile Photo

## Step 1: Save Your Photo
Save your professional photo in this folder (`public/`) with the name:
```
profile.jpg
```

## Step 2: Photo Requirements
- **Format**: JPG, PNG, or WebP
- **Size**: At least 800x800 pixels (square is best)
- **Quality**: High resolution professional photo
- **Style**: Professional headshot with clear face

## Step 3: File Path
The complete path should be:
```
C:\Users\user\Desktop\portfolio website\portfolio-app\public\profile.jpg
```

## What Happens Next?
- The website will automatically detect and display your photo
- It will have a circular frame with golden border
- Beautiful glow effects and animations
- If no photo is found, it shows a golden gradient circle

## Alternative Names (all work):
- `profile.jpg`
- `profile.png`
- `profile.webp`

Just save your photo here and refresh the website! 🎉
